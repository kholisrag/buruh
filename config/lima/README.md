# **Lima Config**

1. the [`lima-config-schema.json`](./lima-config-schema.json) is generated by command (_**Do Not edit it manually**_)

   ```bash
   limactl generate-jsonschema > lima-config-schema.json
   ```

2. [`lima.yaml`](./buruh.yaml) is the configuration file for lima that used especially for running `buruh` worker agent.

   - becareful when editing this file, need to do end to end testing to make sure the configuration is correct for the `buruh` worker agent.
